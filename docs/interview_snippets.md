# Interview snippets

**Personal notes** (gitignored): `docs/interview_snippets.local.md` — copy the entry block from `docs/interview_snippets.example.md`, then **append** new sessions over time.

## Building a practice backlog

1. After a real interview, mock, or “this would be a good SQL drill” moment, add **one dated entry** (a few bullets, no employer details).
2. Under **Repo translation**, point to a repo question once you have one (`questions/...`), or write **not yet modeled** so you can mine it later.
3. Optional: keep a tiny **index** at the top of the local file (date + one-line label + path) so a long log stays scannable.

Cursor agents: when adding or curating `questions/`, `solutions/`, or `data/generators/`, read `docs/interview_snippets.local.md` if it exists so interview-derived style and examples stay in scope.
